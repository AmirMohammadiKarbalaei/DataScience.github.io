Why placeholders are numbered. Repeated values collapse onto one tag, so the model can still reason about “the same person” or “that account” across a long conversation. Here [PERSON_1] covers a bare first name, aliased back to the full name detected earlier in the record.

Why two phone numbers, two tags. Distinct values of the same type stay distinct, so the model can tell the mobile from the work line without ever learning either number.
